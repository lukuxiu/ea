# 北邮 801 通信原理 · 历年真题选择题裁切与在线刷题系统 (2003-2024)

本系统专为**北京邮电大学 801 通信原理**考研冲刺打造，从合并考研真题文档 `ilovepdf_merged.pdf` 中精准提取、裁切并识别了 **2003 年至 2024 年共 21 个年份、633 道选择题/选择填空空位**，并配备了专属的高清选择题 PDF 库与现代化在线逐题刷题网站。

---

## 🚀 快速启动使用

您可以通过以下任意一种方式启动刷题网站：

1. **一键启动本地服务（支持电脑+手机同Wi-Fi实时互通）**：
   - 双击运行根目录下的 `启动刷题网站(推荐).bat`（或 `start_quiz.bat`）；
   - 系统将自动开启本地服务，并弹出浏览器打开 `http://localhost:8080/index.html`；
   - **手机/平板同步刷题**：控制台会打印出您的局域网地址（如 `http://192.168.x.x:8080`），在手机浏览器直接打开该地址即可开始刷题，手机答题记录自动实时同步至电脑！

2. **纯离线免服务直接打开**：
   - 双击根目录下的 `直接双击打开网页.bat`（或 `open_website.bat`），或直接进入 `web/` 文件夹双击 `index.html` 即可直接在浏览器运行。

3. **全平台无网络一键导入导出（任何设备秒级同步）**：
   - 在网页顶部点击 **「多端同步」** 按钮；
   - 点击 **「复制数据同步码」** 或 **「下载备份文件 (.json)」**；
   - 在任意新设备（手机、iPad、新电脑）打开网页，点击 **「从同步码恢复进度」** 粘贴即可无损恢复所有做题记录、正确率统计与错题本！

## 🎯 核心功能特色

### 1. 高清题目原图裁切（解决公式与波形失真痛点）
- 通信原理中包含大量复杂的数学公式（如积分、卷积、傅氏变换、希尔伯特变换、星座图、眼图、匹配滤波器框图等），常规纯文本提取必然发生乱码与丢图；
- 本系统采用 **PyMuPDF 180 DPI 渲染高精度坐标裁切技术**，将每道题的题干、公式、电路图、星座图和选项完美截取为高清原题卡片，跨页题目自动无缝智能拼接，100% 还原真题原貌。

### 2. 一题一练，即时判断对错（能够知道对错）
- 用户逐题作答，点击 `[A]`、`[B]`、`[C]`、`[D]` 选项；
- **即时反馈**：
  - 答对：选项呈现翡翠绿发光高亮，显示 `✓ 回答正确！🎉` 并播放动效；
  - 答错：所选选项呈现绯红震动，标准答案以绿光显眼提示，显示 `❌ 回答错误，已自动加入错题本`；
- 支持 **答对后自动跳至下一题**（可自由开关）。

### 3. 多种刷题模式
- **年份专练**：可自由切换 2024、2023、2022……直至 2003 年，按年份集中突破；
- **全真随机抽测**：从 633 道历年考研真题库中随机抽取 30 题进行综合强化模拟；
- **错题本模式**：自动记录所有做错的题，提供错题专项复习与掌握消题功能；
- **我的收藏**：随时点击卡片右上角五角星收藏核心重点与经典考题。

### 4. 答题卡快速跳转与数据统计
- 内置悬浮答题卡弹窗，红、绿、灰三色直观展示各题完成与正误情况，点击题号一秒直达对应题；
- 实时统计 **已做题数 / 总题数 / 正确数 / 错误数 / 正确率百分比**，并附带动态进度条；
- 所有刷题记录通过浏览器 `localStorage` 本地持久化保存，刷新或关闭浏览器后进度不丢失。

### 5. 便捷操作与键盘快捷键
- **A / B / C / D**：快捷选择对应选项；
- **← / → 方向键**：快速切换上一题 / 下一题；
- **空格键 / 回车键**：快速显示 / 隐藏参考答案；
- **放大镜 / 点击图片**：唤出超清图片灯箱缩放预览。
