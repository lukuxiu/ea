# 北邮 801 通信原理历年真题刷题网站

这是根据上传的历年真题 PDF 整理出的纯静态刷题网站。

## 内容

- 覆盖 PDF 中出现客观题的 24 个年份：1998, 2002, 2003, 2004, 2005, 2006, 2007, 2008, 2009, 2010, 2011, 2012, 2013, 2014, 2015, 2016, 2017, 2018, 2019, 2020, 2021, 2022, 2023, 2024
- 共整理约 451 个可刷题卡片
- 选择题 / 选择填空题
- 填空题
- 判断题
- 自带 PDF 参考答案
- 手机端自适应
- 上一题 / 下一题 / 随机题
- 本地 `localStorage` 保存“不会 / 已掌握”状态
- 可从每道题直接打开原题 PDF 对应页
- 完全静态，无后端

## 本地打开

直接双击 `index.html` 在部分浏览器中可能因为浏览器禁止本地 `fetch` 而无法加载 JSON。

推荐在此目录运行：

```bash
python -m http.server 8000
```

然后访问：

```text
http://localhost:8000
```

## 部署到 GitHub Pages

1. 新建一个 GitHub 仓库，例如 `bupt-801-quiz`。
2. 把本目录下的 `index.html`、`questions.json`、`source.pdf` 上传到仓库根目录。
3. GitHub → Settings → Pages。
4. Source 选择 `Deploy from a branch`。
5. Branch 选择 `main`，目录选择 `/ (root)`。
6. 保存，等待 GitHub Pages 发布。

发布后就是一个手机也能直接刷的静态网站。

## 注意

题目和答案以用户上传 PDF 为准，没有对资料中的参考答案进行二次校正。部分老年份的 OCR 数学公式可能显示得不如原 PDF，遇到看不清的题可点击“查看原题 PDF”。
